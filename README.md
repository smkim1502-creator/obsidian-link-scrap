# 링크 스크랩 (옵시디언 플러그인)

링크를 넣으면 글 본문을 가져와 `스크랩` 폴더에 노트로 저장한다. PC·모바일 공용.

## 설치 (휴대폰·다른 기기)

1. 옵시디언 설정 → 커뮤니티 플러그인 → 탐색 → **BRAT** 설치 후 켜기
2. 명령 팔레트 → `BRAT: Add a beta plugin for testing` → `smkim1502-creator/obsidian-link-scrap` 입력 → 추가
3. 커뮤니티 플러그인 목록에서 「링크 스크랩」 켜기

새 버전은 BRAT이 자동으로 받아 온다. 배포: `manifest.json`의 version을 올리고 같은 이름의 태그를 push하면 GitHub Actions가 릴리스를 만든다.

## 저장 형식

```markdown
---
url: https://brunch.co.kr/@hiclemi/152
tags:
  - AI
---
# 글 제목

본문…
```

- 파일 이름 = 글 제목. 같은 이름이 있으면 `제목 (2).md`
- **폴더 자동 분류** (1.2.0~): 비슷한 스크랩·같은 사이트 글이 모인 하위 폴더(예: `스크랩/AI`, `스크랩/게임/공식`)를 고른다. 어느 폴더와도 안 맞으면 `스크랩`에 둔다. 기존 스크랩 기준 적중률 80%, 닌텐도 키워드 시리즈 99%
- **자동 태그·관련 노트** (1.1.0~, 외부 API 없이 기기 안에서 계산)
  - 태그: 저장할 폴더에서 주로 쓰는 태그(예: `스크랩/AI` → `AI`) + 본문에 이름이 여러 번 나오는 기존 태그 + 아주 비슷한 노트의 태그. 입력창에 쓴 태그와 합쳐진다
  - 관련 노트: 내용이 비슷하거나 본문에 제목이 나오는 **내 노트**(스크랩 폴더 밖)를 frontmatter 아래 `관련 노트: [[…]]` 줄로 최대 3개
  - 기존에 직접 달아 둔 링크로 측정한 적중률: 스크랩 62%, 닌텐도 키워드 시리즈 86% / 태그 71% (`node test/eval_related.mjs`)
- 이미 스크랩한 링크(추적용 파라미터만 다른 경우 포함)는 새로 만들지 않고 기존 노트를 연다
- PDF 링크는 PDF 파일을 같은 폴더에 저장하고 노트에 임베드한다
- 본문을 못 찾는 페이지(SNS 등)는 미리보기 이미지·요약만 저장하고 알림으로 알려준다

## 쓰는 법

| 방법 | 동작 |
|------|------|
| 왼쪽 리본의 신문 아이콘 / 명령 `링크 스크랩` | 입력창. 클립보드에 링크가 있으면 자동으로 채워짐. 폴더(기본: 자동 분류)·태그 선택 후 Enter |
| 명령 `클립보드 링크 바로 스크랩` | 입력창 없이 바로 저장 (자동 분류, 끄면 마지막에 고른 폴더) |
| `obsidian://scrap?url=…` | 다른 앱에서 호출 (모바일 공유 시트용). `&folder=스크랩/AI` `&tags=AI,경제` `&ask=1`(입력창 띄우기) 선택 |

### 모바일에서 빠르게 쓰기
- **공통**: 설정 → 모바일 → 빠른 실행(Quick action)을 `링크 스크랩: 클립보드 링크 바로 스크랩`으로 지정
  → 링크 복사 → 옵시디언 열기 → 화면을 아래로 당기기
- **아이폰 공유 시트**: 단축어 앱 → 새 단축어
  1. 단축어 설정(ⓘ)에서 "공유 시트에서 보기" 켜기, 입력 유형 `URL`
  2. 동작 `URL 인코딩` (입력: 단축어 입력)
  3. 동작 `URL 열기`: `obsidian://scrap?url=`[URL 인코딩된 텍스트]
  → 사파리·앱에서 공유 → 단축어 이름 누르기

## 사이트별 처리

| 사이트 | 처리 |
|--------|------|
| 디시인사이드 | PC 주소도 모바일 페이지로 가져옴, 말머리 제거 |
| 네이버 블로그 | PC 주소(iframe)를 모바일 페이지로 바꿔 가져옴 |
| 네이버 뉴스, 브런치, 루리웹, 티스토리, GeekNews | 본문 영역 직접 지정 |
| 토스증권 콘텐츠 | 화면이 자바스크립트로 그려져서 내부 API로 본문을 받음 |
| 아카라이브 등 Cloudflare 보호 사이트 | 막히면 PC에서는 숨은 브라우저 창으로 다시 시도, 모바일은 실패 알림 |
| 그 밖의 사이트 | Firefox 읽기 모드와 같은 Readability로 본문 추출 |

새 사이트 규칙은 `src/extract.js`의 `SITE_RULES`에 추가한다.

## 설정

- 스크랩 최상위 폴더 (기본 `스크랩`) — 이 폴더와 하위 폴더가 입력창 목록에 나옴
- 폴더 자동 분류 (기본 켬)
- 이미지를 Vault에 저장 (기본 끔) — 켜면 `_resources/스크랩/{노트 제목}/01.jpg …`로 받아 `![[…]]`로 넣음
- 스크랩 후 노트 열기 (기본 켬)
- 태그 자동으로 달기 / 관련 노트 자동으로 링크 (기본 켬), 관련 노트 최대 개수 (기본 3)
- 비교에서 뺄 폴더 (기본 `클로드 코드 프로젝트, 해결해야 할 문제`)

## 개발

```
npm install
node test/run.mjs [url …]   # 실제 사이트로 추출 결과 확인 → test/tmp_out/
node test/plugin.mjs        # 가짜 옵시디언 환경에서 플러그인 전체 흐름 검사
node test/eval_related.mjs  # 자동 태그·관련 노트 적중률 (실제 Vault 읽기만)
DEBUG=1 node test/real_vault.mjs "스크랩/경제" url …  # 실제 Vault 기준으로 새 글 스크랩 결과·후보 점수 보기 (메모리에서만 저장)
node build.mjs --install    # 빌드 후 Vault 플러그인 폴더에 복사
```

| 파일 | 역할 |
|------|------|
| `src/extract.js` | HTML → 제목·본문 추출, 사이트별 규칙, 인코딩 처리 |
| `src/scrap.js` | URL 하나를 가져와 마크다운까지 만드는 흐름 (주소 정리·리다이렉트·iframe·차단 감지) |
| `src/related.js` | 자동 태그·관련 노트: 2글자 단위 TF-IDF 유사도, 제목 언급, 폴더 태그 |
| `src/main.js` | 옵시디언 플러그인: 입력창, 저장, 중복 감지, 이미지 저장, 자동 태그·링크, 설정, `obsidian://scrap` |
| `build.mjs` | esbuild 번들 → `dist/`, `--install` 시 Vault에 복사 |
| `test/` | 추출 검증·플러그인 흐름 검사 |
