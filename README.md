# 링크 스크랩 (옵시디언 플러그인)

링크를 넣으면 글 본문을 가져와 `스크랩` 폴더에 노트로 저장한다. 원문/한국어 번역, 전문/요약 중에서 골라 저장할 수 있고, 번역·요약은 마지막에 PC의 Claude가 확인한다. PC·모바일 공용.

## 설치 (휴대폰·다른 기기)

1. 옵시디언 설정 → 커뮤니티 플러그인 → 탐색 → **BRAT** 설치 후 켜기
2. 명령 팔레트 → `BRAT: Add a beta plugin for testing` → `smkim1502-creator/obsidian-link-scrap` 입력 → 추가
3. 커뮤니티 플러그인 목록에서 「링크 스크랩」 켜기

새 버전은 BRAT이 자동으로 받아 온다. 배포: `manifest.json`의 version을 올리고 같은 이름의 태그를 push하면 GitHub Actions가 릴리스를 만든다.

## 저장 형식

```markdown
---
url: https://brunch.co.kr/@hiclemi/152
tags:
  - AI
---
# 글 제목

본문…
```

- 파일 이름 = 글 제목. 같은 이름이 있으면 `제목 (2).md`
- **폴더 자동 분류** (1.2.0~): 비슷한 스크랩·같은 사이트 글이 모인 하위 폴더(예: `스크랩/AI`, `스크랩/게임/공식`)를 고른다. 어느 폴더와도 안 맞으면 `스크랩`에 둔다. 기존 스크랩 기준 적중률 80%, 닌텐도 키워드 시리즈 99%
- **자동 태그·관련 노트** (1.1.0~, 외부 API 없이 기기 안에서 계산)
  - 태그: 저장할 폴더에서 주로 쓰는 태그(예: `스크랩/AI` → `AI`) + 본문에 이름이 여러 번 나오는 기존 태그 + 아주 비슷한 노트의 태그. 입력창에 쓴 태그와 합쳐진다
  - 관련 노트: 내용이 비슷하거나 본문에 제목이 나오는 **내 노트**(스크랩 폴더 밖)를 frontmatter 아래 `관련 노트: [[…]]` 줄로 최대 3개
  - 기존에 직접 달아 둔 링크로 측정한 적중률: 스크랩 62%, 닌텐도 키워드 시리즈 86% / 태그 71% (`node test/eval_related.mjs`)
- 이미 스크랩한 링크(추적용 파라미터만 다른 경우 포함)는 새로 만들지 않고 기존 노트를 연다
- PDF 링크는 PDF 파일을 같은 폴더에 저장하고 노트에 임베드한다
- 본문을 못 찾는 페이지(SNS 등)는 미리보기 이미지·요약만 저장하고 알림으로 알려준다

## 쓰는 법

| 방법 | 동작 |
|------|------|
| 왼쪽 리본의 신문 아이콘 / 명령 `링크 스크랩` | 입력창. 클립보드에 링크가 있으면 자동으로 채워짐. 폴더(기본: 자동 분류)·태그·언어(원문/한국어 번역)·분량(전문/요약) 선택 후 Enter |
| 명령 `클립보드 링크 바로 스크랩` | 입력창 없이 바로 저장 (자동 분류, 끄면 마지막에 고른 폴더). 언어·분량은 설정의 기본값 |
| `obsidian://scrap?url=…` | 다른 앱에서 호출 (모바일 공유 시트용). `&folder=스크랩/AI` `&tags=AI,경제` `&translate=1`(한국어 번역) `&summary=1`(요약) `&ask=1`(입력창 띄우기) 선택 |
| 명령 `Claude 확인 대기 노트 모두 마무리` (PC) | 확인 대기 표시가 있는 노트를 지금 마무리 (보통은 자동으로 함) |
| 명령 `이 노트 Claude로 마무리` (PC) | 열어 둔 확인 대기 노트를 마무리. 초안을 고친 노트도 덮어쓴다 |

## 번역·요약

입력창에서 **언어**(원문 / 한국어 번역)와 **분량**(전문 / 요약)을 고른다. API 키는 쓰지 않는다.
초안은 무료 방식으로 만들고, 마지막에 PC에 설치된 Claude Code(로그인한 구독 계정, `claude -p --safe-mode`)가 확인해 최종본으로 만든다.

| | 초안 (휴대폰·PC) | Claude 마무리 (PC) |
|---|---|---|
| 전문 번역 | 구글 번역 웹 주소(키 없음)로 마크다운째 번역. 이미지·링크 주소·코드·표 구분선은 자리표시로 지켜 둔다. 1~6초 | 원문과 구글 번역을 줄마다 짝지어 보여 주고, 오역·빠진 내용·고유명사·어색한 문장을 고친 줄만 받아 바꾼다. (Haiku 기준) 짧은 글 10~20초, 1만 6천 자 약 1분 40초, 3만 7천 자 약 5분. Sonnet은 생각을 덜 해서 묶음당 절반쯤 |
| 요약 | 기기 안에서 핵심 문장 3~6개를 골라 목록으로 (TextRank: 다른 문장과 많이 겹치는 문장 + 첫머리·제목 가산점). 번역+요약이면 고른 문장만 구글 번역 | 원문을 읽고 요지 한두 문장 + 항목 3~7개로 새로 쓴다. 번역+요약이면 바로 한국어로. 5~15초 |
| 외국어 제목 별칭 | 구글 번역 | Claude가 다시 옮긴다 |

- **PC에서 스크랩**하면 Claude가 마무리한 결과를 바로 저장한다
- **휴대폰에서 스크랩**하면 초안을 저장하고 frontmatter에 `Claude: 번역 확인 대기 (3f2a1b9c)` 같은 표시를 단다. PC 옵시디언이 동기화로 이 노트를 받으면(켜 두었으면 동기화 뒤 15초쯤, 꺼져 있었으면 다음에 켤 때) 원문을 다시 받아 마무리하고 표시를 지운다. 제목이 바뀌면 파일 이름도 바꾼다
- 괄호 안은 초안의 지문이다. 마무리 전에 노트 본문(또는 별칭)을 고쳤으면 고친 내용을 지키려고 마무리하지 않는다. 그래도 마무리하려면 PC에서 노트를 열고 명령 `이 노트 Claude로 마무리`
- 전문 번역을 처음부터 Claude에게 맡기지 않는 이유: 시험해 보니 Claude가 기사·에세이 전문 번역은 저작권을 이유로 대부분 거절하고 요약을 내놓았다. 이미 있는 번역문을 원문과 대조해 고치는 일은 한다
- 긴 글은 원문+번역 8,000자 안팎씩 나눠 두 개씩 동시에 확인한다(Claude Code 하나가 메모리 200MB 남짓). 한자·가나 글이면 먼저 고유명사 표기를 정해 모든 묶음에 같은 이름을 쓰게 한다
- Claude가 실행되지 않으면(로그인 만료·사용량 한도·시간 초과) 초안으로 저장하고 확인 대기 표시를 단다. Claude가 응답했지만 쓸 수 없는 결과(거절 등)면 초안을 그대로 두고 표시는 달지 않는다(이미 있으면 지운다)
- 고친 줄은 이미지·링크 자리와 줄 앞 마크다운 기호가 그대로이고, 구글 번역보다 절반 넘게 짧아지지 않았을 때만 쓴다

- 한국어 글은 번역하지 않는다 (한글이 글자의 절반 이상이면 한국어 글. 영어 단어는 한 단어를 한글 1.5자로 친다)
- 요약 노트는 맨 위에 본문의 첫 이미지를 두고 요약만 저장한다. 원문은 `url`로 찾아간다
- 번역하면 제목도 한국어로 바뀌고, 폴더 자동 분류·태그·관련 노트도 한국어로 옮긴 글로 계산한다
- 원문으로 저장한 외국어 글은 한국어로 옮긴 제목을 `aliases`에 넣는다 (기존 일본어 스크랩 노트와 같은 방식)
- 구글 번역까지 실패하면 원문으로 저장하고 알림에 이유를 적는다
- PDF와 본문을 못 찾은 페이지(미리보기만 저장)는 번역·요약하지 않는다 (미리보기는 번역만 함)

### 모바일에서 빠르게 쓰기
- **공통**: 설정 → 모바일 → 빠른 실행(Quick action)을 `링크 스크랩: 클립보드 링크 바로 스크랩`으로 지정
  → 링크 복사 → 옵시디언 열기 → 화면을 아래로 당기기
- **아이폰 공유 시트**: 단축어 앱 → 새 단축어
  1. 단축어 설정(ⓘ)에서 "공유 시트에서 보기" 켜기, 입력 유형 `URL`
  2. 동작 `URL 인코딩` (입력: 단축어 입력)
  3. 동작 `URL 열기`: `obsidian://scrap?url=`[URL 인코딩된 텍스트]
  → 사파리·앱에서 공유 → 단축어 이름 누르기

## 사이트별 처리

| 사이트 | 처리 |
|--------|------|
| 디시인사이드 | PC 주소도 모바일 페이지로 가져옴, 말머리 제거 |
| 네이버 블로그 | PC 주소(iframe)를 모바일 페이지로 바꿔 가져옴 |
| 네이버 뉴스, 브런치, 루리웹, 티스토리, GeekNews | 본문 영역 직접 지정 |
| 토스증권 콘텐츠 | 화면이 자바스크립트로 그려져서 내부 API로 본문을 받음 |
| 아카라이브 등 Cloudflare 보호 사이트 | 막히면 PC에서는 숨은 브라우저 창으로 다시 시도, 모바일은 실패 알림 |
| 그 밖의 사이트 | Firefox 읽기 모드와 같은 Readability로 본문 추출 |

새 사이트 규칙은 `src/extract.js`의 `SITE_RULES`에 추가한다.

## 설정

- 스크랩 최상위 폴더 (기본 `스크랩`) — 이 폴더와 하위 폴더가 입력창 목록에 나옴
- 폴더 자동 분류 (기본 켬)
- 이미지를 Vault에 저장 (기본 끔) — 켜면 `_resources/스크랩/{노트 제목}/01.jpg …`로 받아 `![[…]]`로 넣음
- 스크랩 후 노트 열기 (기본 켬)
- 태그 자동으로 달기 / 관련 노트 자동으로 링크 (기본 켬), 관련 노트 최대 개수 (기본 3)
- 비교에서 뺄 폴더 (기본 `클로드 코드 프로젝트, 해결해야 할 문제`)
- 기본 언어 (원문) / 기본 분량 (전문) — 입력창의 처음 값이자 `클립보드 링크 바로 스크랩`의 값
- 외국어 제목에 한국어 별칭 달기 (기본 켬)
- Claude로 마무리 (기본 켬) — PC: Claude Code로 번역 확인·요약·별칭, 휴대폰 초안 마무리. 휴대폰: 초안에 확인 대기 표시 달기
- Claude 모델 (기본 Sonnet / Haiku), Claude Code 실행 파일 (비우면 `~/.local/bin/claude.exe` 등 기본 위치) — PC만

## 개발

```
npm install
node test/run.mjs [url …]   # 실제 사이트로 추출 결과 확인 → test/tmp_out/
node test/transform.mjs [--claude] [--mode=번역,요약,번역요약] [url …]  # 번역·요약 결과 → test/tmp_out/transform/
node test/plugin.mjs        # 가짜 옵시디언 환경에서 플러그인 전체 흐름 검사 (휴대폰처럼 초안 + 가짜 Claude로 마무리 흐름)
node build.mjs && node test/plugin-desktop.mjs  # 빌드한 main.js를 PC처럼 실행 (Claude Code를 실제로 부름: 번역 확인·요약·별칭·휴대폰 초안 마무리)
node test/eval_related.mjs  # 자동 태그·관련 노트 적중률 (실제 Vault 읽기만)
DEBUG=1 node test/real_vault.mjs "스크랩/경제" url …  # 실제 Vault 기준으로 새 글 스크랩 결과·후보 점수 보기 (메모리에서만 저장)
node build.mjs --install    # 빌드 후 Vault 플러그인 폴더에 복사
```

| 파일 | 역할 |
|------|------|
| `src/extract.js` | HTML → 제목·본문 추출, 사이트별 규칙, 인코딩 처리 |
| `src/scrap.js` | URL 하나를 가져와 마크다운까지 만드는 흐름 (주소 정리·리다이렉트·iframe·차단 감지) |
| `src/related.js` | 자동 태그·관련 노트: 2글자 단위 TF-IDF 유사도, 제목 언급, 폴더 태그 |
| `src/transform.js` | 번역·요약: 한국어 판별, 구글 번역(자리표시로 마크다운 지키기), 핵심 문장 고르기, Claude 번역 확인(줄 짝짓기·묶음 나누기·고유명사 표기)·요약 |
| `src/pending.js` | "Claude 확인 대기" 표시 달기·읽기, 초안 지문(고친 노트 덮어쓰지 않기) |
| `src/claude.js` | PC의 Claude Code를 구독 계정으로 실행 (`-p --safe-mode --tools ""`) |
| `src/main.js` | 옵시디언 플러그인: 입력창, 저장, 중복 감지, 이미지 저장, 자동 태그·링크, 설정, `obsidian://scrap` |
| `build.mjs` | esbuild 번들 → `dist/`, `--install` 시 Vault에 복사 |
| `test/` | 추출 검증·플러그인 흐름 검사 |
